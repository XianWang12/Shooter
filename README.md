# Shooter —— 3D 俯视角生存射击游戏

基于 Unity 与 C# 开发的 3D 俯视角生存射击游戏，围绕敌人 AI、波次生成、技能管理、对象池优化及事件驱动架构进行设计，注重系统模块化、代码可维护性与运行效率。

## 📖 项目简介

Shooter 是一款 3D 俯视角生存射击类游戏。玩家需要在持续生成的敌人威胁下进行战斗与生存。

项目采用模块化的游戏系统设计，将角色状态管理、敌人 AI、波次控制、技能调用、击杀计分与 Buff 效果等功能进行拆分，通过状态机、协程、事件驱动和对象池等机制降低系统耦合，提高功能扩展性与运行效率。

**项目重点：** 游戏 AI 架构设计、敌人波次管理、对象池优化、技能系统设计、事件驱动机制与 Buff 生命周期管理。

## ✨ 核心功能与技术实现

### 1. 基于 FSM 的角色与敌人 AI

* 采用有限状态机（FSM）管理角色与敌人的行为状态，将不同敌人类型的状态逻辑拆分为独立状态类。
* 统一状态管理入口，规范状态切换与行为执行流程。
* 将不同敌人的行为逻辑与通用状态管理机制分离，便于新增敌人类型及扩展 AI 行为。
* 通过模块化状态设计降低角色、敌人行为之间的耦合，提高代码可维护性。

### 2. 基于协程的波次生成系统

* 使用协程控制敌人波次的生成流程，实现波次循环与生成节奏管理。
* 通过难度曲线控制波次推进，使敌人生成与游戏进程相结合。
* 利用敌人死亡事件回调维护存活敌人数量，在满足推进条件后自动进入下一波。
* 将波次控制、敌人生命周期与难度管理分离，避免轮询与强耦合逻辑。

### 3. 基于 Unity ObjectPool 的对象池系统

* 基于 `UnityEngine.Pool.ObjectPool<T>` 构建可复用的敌人对象池。
* 按 `EnemyType` 区分不同类型的敌人，实现分类缓存与对象复用。
* 通过统一接口规范对象的获取、启用、回收及生命周期重置流程。
* 为血液命中特效、烟雾等频繁创建的视觉特效建立独立 VFX 对象池。
* 减少频繁调用 `Instantiate`、`Destroy` 所带来的开销，降低垃圾回收（GC）压力。

### 4. 模块化技能系统

* 使用单例统一管理技能入口，集中处理技能调用与管理逻辑。
* 通过统一的调用入口降低技能使用方与具体技能实现之间的依赖。
* 为后续新增技能及扩展技能管理逻辑提供基础。

### 5. 事件驱动的击杀计分系统

* 采用事件驱动机制解耦敌人死亡、击杀计分与 UI 更新。
* 统一管理不同敌人类型对应的击杀分值规则。
* 通过事件传递击杀结果，避免敌人逻辑直接依赖计分 UI。
* 提高计分系统的独立性，便于后续扩展连杀奖励、特殊敌人奖励等规则。

### 6. 玩家 Buff 效果管理

* 编写玩家 Buff 控制器，统一管理 Buff 的添加、持续时间与移除。
* 支持相同 Buff 的持续时间叠加。
* 在 Buff 结束时恢复对应属性，并提供全量清理机制。
* 使用协程管理持续时间与到期回收逻辑，减少手动计时与生命周期管理的复杂度。

## 🏗️ 架构设计重点

本项目围绕以下几个方面进行系统设计：

* **职责分离：** 将 AI 状态、波次控制、技能管理、计分逻辑和 Buff 管理拆分为独立模块。
* **低耦合设计：** 使用事件回调连接敌人死亡与计分流程，避免不同系统之间直接依赖。
* **生命周期管理：** 通过统一接口规范敌人和特效对象的启用、重置及回收。
* **性能优化：** 对高频生成的敌人与视觉特效使用对象池，减少不必要的对象创建与销毁。
* **可扩展性：** 通过状态类、敌人类型划分和统一管理入口，为后续功能扩展提供基础。

## 🚀 项目运行

### 环境要求

* Unity Editor：请以 `ProjectSettings/ProjectVersion.txt` 中记录的版本为准。
* Git：用于克隆项目（可选）。

### 获取项目

```bash
git clone https://github.com/XianWang12/Shooter.git
```

### 打开项目

1. 使用 Unity Hub 添加克隆后的项目目录。
2. 使用与项目配置兼容的 Unity 版本打开项目。
3. 等待 Unity 完成资源导入与脚本编译。
4. 在 `Assets` 目录中找到项目实际使用的主场景。
5. 打开场景并点击 Unity 编辑器中的播放按钮运行。

## 📁 项目目录

```text
Shooter/
├── Assets/          # 游戏资源、场景、脚本与预制体
├── Packages/        # Unity 依赖包
├── ProjectSettings/ # 项目配置
├── .gitignore
└── .gitattributes
```

以上为 Unity 项目顶层目录，具体脚本模块以 `Assets` 内的实际组织结构为准。

# 🔫 Shooter —— 3D 波次生存射击游戏

一个基于 **Unity 2022.3** 与 **C#** 开发的 3D 波次生存射击项目。玩家在场景中自由移动、用鼠标瞄准并持续射击，抵御一波波不断增强的敌人。项目重点实践**有限状态机（FSM）、对象池、技能模块化、敌人 AI、道具与增益系统**等游戏系统的设计与实现。

## 📖 项目简介

Shooter 是一款以俯视角射击和波次生存为核心的 3D 动作射击游戏。玩家在场地中移动、射击并施放技能，面对兔子、熊、大象三类行为各异的敌人。随着波次推进，敌人数量与种类逐步增加；击败敌人可获得分数并掉落道具，通过回复生命、临时提升暴击或移速来延长生存时间。生命值归零即游戏结束，玩家可在结算界面重新开始或返回主菜单。

项目的主要开发重点包括：**玩家与敌人的分层状态机、可切换的技能系统、基于 `ObjectPool` 的敌人与特效复用、属性/异常状态计算、以及 UI 与音频的解耦**。

## ✨ 核心功能与技术实现

### 1. 玩家状态机与移动瞄准

- 使用有限状态机管理玩家行为，将待机、移动、死亡等行为拆分为独立状态（`PlayerIdleState`、`PlayerMoveState`、`PlayerDeadState`）。
- 通过统一的 `PlayerState` 基类与 `PlayerStateMachine` 组织状态切换，状态在 `Enter/Update/FixedUpdate/Exit` 中统一处理动画布尔量、计时与输入。
- 移动采用 `Rigidbody.MovePosition` 在 `FixedUpdate` 中推进，避免逐帧速度累加带来的抖动。
- 瞄准通过摄像机向鼠标位置的射线与地面 `LayerMask` 相交求得目标点，再使用 `Quaternion.Slerp` 平滑旋转角色朝向，实现俯视角下的鼠标瞄准。
- 玩家死亡时状态机切换到死亡状态，并清理身上的增益效果。

### 2. 三种敌人 AI 与状态机

敌人同样使用有限状态机，并在 `Enemy` 基类中统一处理动画、导航代理（`NavMeshAgent`）、血条与受击特效。

- **兔子（`Enemy_Bunny`）：** 待机、移动、冲刺与死亡状态。当与目标距离进入冲刺范围且拥有视线（射线检测是否被地形遮挡）时，切换到冲刺状态，使用 `Vector3.Lerp` 沿直线突进。
- **熊（`Enemy_Bear`）：** 待机、移动、狂暴与死亡状态。移动一段时间后进入狂暴状态，提升移动速度并将普通撕咬替换为间隔更短、附带**流血**效果的狂暴撕咬。
- **大象（`Enemy_Elephant`）：** 待机、移动、吸附、召唤与死亡状态。进入吸附范围后把玩家向自身拉拽；吸附结束后召唤增援（3 只兔子 + 1 只熊，并有小概率额外召唤 1 只大象）。

敌人的寻路统一使用 `NavMeshAgent.SetDestination`，并以 `Bait.Current`（诱饵）为优先目标，否则追踪玩家，从而让诱饵技能能够吸引敌人。

### 3. 技能系统与技能管理器

项目包含 4 个主动技能，均继承自统一的 `Skill` 基类：

- **诱饵（`Bait_Skill`）：** 生成一个不断前进并放大的诱饵，吸引敌人仇恨；期间玩家进入无敌，诱饵结束或到达时长后爆炸，对范围内敌人造成伤害。
- **闪现（`Flash_Skill`）：** 沿当前移动方向（或角色朝向）进行短距离位移，并通过射线检测避免穿过地形。
- **炮塔（`Turret_Skill`）：** 生成限时自动炮塔，使用 `Physics.OverlapSphere` 搜索最近敌人、平滑转向并用射线激光持续攻击，到时自动销毁。
- **地雷（`Landmine_Skill`）：** 在脚下放置地雷，敌人触发后对球形范围内敌人造成伤害并播放爆炸特效。

`Skill` 基类统一管理冷却计时与 `CanUse()/Use()` 调用入口；`SkillManager` 单例集中持有各技能实例。各技能通过独立的控制器脚本（`*_Skill_Controller`）与 `SetUp...(...)` 方法在运行时注入参数，使技能数值可在检视面板配置而无需改动调用逻辑。

### 4. 波次系统与敌人对象池

- `EnemyWave` 使用协程驱动波次循环：显示当前波次 → 生成敌人 → 等待全部敌人被消灭 → 间隔后进入下一波。
- 敌人数量随波次按公式增长：兔子 `wave + 4`；熊从第 3 波开始（`wave - 2`）；大象从第 7 波开始（`wave - 6`）。
- 从预设生成点列表中随机选取位置刷怪，并订阅每个敌人的 `OnDeath` 事件以统计存活数量。
- `EnemyPool` 基于 `UnityEngine.Pool.ObjectPool<T>` 按敌人类型（`EnemyType`）建立对象池，统一处理创建、取出、归还与销毁；`IPoolable` 接口规定 `OnSpawned/OnDespawned` 生命周期，池对象在取出时重置属性与导航状态，死亡后延迟回收，避免频繁的实例化与销毁。

### 5. 战斗、属性与异常状态

- `CharacterStats` 作为属性基类，统一管理最大/当前生命值、伤害、受击与死亡，并通过 `OnHealthChanged` 事件驱动 UI 刷新。
- `PlayerStats` 在此基础上加入**暴击**（概率造成双倍伤害）、**无敌帧**与受击音效；`EnemyStats` 负责死亡时结算分数、播放对应音效并触发掉落。
- **流血（Bleeding）：** 通过 `CauseBleedingTo` 与协程按秒结算持续伤害，重复施加时会停止旧协程后重新计时。
- **回复（Heal）：** 以 `Mathf.Min` 限制不超过最大生命值，死亡单位不再回复。
- 战斗计算包含暴击判定与按敌人类型的差异化处理，数值与状态通过委托/事件与表现层解耦。

### 6. 道具掉落、拾取与增益

- `ItemDrop` 以 `[System.Serializable]` 数组配置可掉落物与掉落概率，敌人死亡时按概率实例化道具。
- `PickUp` 定义三类道具（生命、速度、力量），在 `OnTriggerEnter` 中识别玩家并施加效果：
  - **生命药水：** 立即恢复生命。
  - **速度药水：** 临时提升移动速度。
  - **力量药水：** 临时提升暴击率。
- `PlayerBuffController` 统一管理限时增益：首次拾取时记录原始值并修改属性，重复拾取时只延长持续时间；通过协程在到期后恢复原始值，并提供 `ClearAllBuffs()` 供死亡等场景统一清理。

### 7. 对象池化视觉特效

- `HitBloodPool` 与 `SmokePool` 同样基于 `ObjectPool<T>` 复用粒子特效，按粒子时长自动归还，避免战斗中频繁生成/销毁特效造成卡顿。
- 敌人受击时通过 `PlayHitFX` 从命中点与法线方向播放血液特效；大象召唤时先播放烟雾、待烟雾结束后再在其位置生成增援。

### 8. 界面、音频与相机

- **主菜单（`UI_MainMenu`）：** 开始游戏、打开/关闭玩法指引与设置、退出游戏，通过 `SceneManager` 在 `MainMenu` 与 `MainScene` 间切换。
- **暂停菜单（`UI_Options`）：** 继续、重开、返回主菜单；`UI` 以 `Time.timeScale` 实现暂停/恢复。
- **游戏内界面（`UI_InGame`）：** 生命条与数值、受击红色渐变提示、分数、波次提示、技能冷却环形遮罩、增益图标以及死亡结算界面，通过事件订阅刷新数据。
- **音量设置（`UI_VolumeSlider`）：** 使用 `AudioMixer` 的 `SetFloat` 与 `Mathf.Log10` 将滑条值转换为分贝，并通过 `PlayerPrefs` 持久化。
- **音频管理器（`AudioManager`）：** 单例集中管理 `AudioSource` 数组，播放时加入随机音高，并按敌人类型选择受击/死亡音效。
- **相机（`CameraFollow`）：** 在开始时记录与玩家的偏移，之后平滑跟随。

## 📁 主要脚本结构

```text
Assets/Scripts/
├── Camera/            # 相机跟随
├── Entity/            # 游戏实体
│   ├── Entity.cs      # 实体基类（动画、刚体）
│   ├── Player/        # 玩家控制器、状态机与各状态、射击、增益控制
│   └── Enemy/         # 敌人基类、状态基类、波次与撕咬
│       ├── Bear/      # 熊：待机、移动、狂暴、死亡与狂暴撕咬
│       ├── Bunny/     # 兔子：待机、移动、冲刺、死亡
│       └── Elephant/  # 大象：待机、移动、吸附、召唤、死亡
├── Item/              # 道具掉落与拾取
├── Managers/          # 技能、玩家、分数与音频管理器
├── Pooling/           # 对象池
│   ├── Enemy/         # 敌人对象池与池化接口
│   └── VFX/           # 受击血液与烟雾特效池
├── Skill/             # 技能基类与各技能
│   └── SkillController/  # 技能运行时控制器（诱饵/地雷/炮塔）
├── Stats/             # 角色属性、玩家属性与敌人属性
└── UI/                # 主菜单、暂停、游戏内 HUD、引导与音量
```

## 🚀 如何运行

1. 克隆仓库：

   ```bash
   git clone https://github.com/XianWang12/Shooter.git
   ```

2. 使用 Unity Hub「添加」，选择克隆后的 `Shooter` 文件夹。
3. 使用 Unity `2022.3.62f3c1` 或兼容版本打开项目，等待资源导入与脚本编译完成。
4. 在 `Assets/Scenes` 中打开主菜单场景 `MainMenu`（或按要求从构建场景列表的第一个场景进入）。
5. 点击 Unity 编辑器顶部的播放按钮运行；进入游戏后从主菜单点击开始游戏。

> 构建场景列表中依次为 `Assets/Scenes/MainMenu.unity` 与 `Assets/Scenes/MainScene.unity`，请从主菜单进入以获得完整流程。

## 🔮 项目中体现的设计思路

- **状态与行为分离：** 玩家与三类敌人各自使用状态类管理不同行为，减少控制器中的条件堆叠。
- **数据与表现解耦：** 属性变化通过事件通知 UI，敌人死亡通过事件通知波次系统。
- **对象复用：** 敌人与特效统一使用对象池，降低运行时内存分配与 GC 压力。
- **技能模块化：** 以 `Skill` 基类统一冷却入口，具体技能继承实现，数值通过 `SetUp...` 注入，便于扩展新技能。
- **限时增益可叠加时长：** 增益控制器记录原始值并在到期后还原，重复拾取只延长持续。

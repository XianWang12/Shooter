🔫 Shooter

一个基于 Unity 引擎开发的射击类游戏项目，使用 C# 编写游戏逻辑，主要用于实践射击游戏玩法与 Unity 游戏开发技术。

📖 项目简介

Shooter 是一个使用 Unity 开发的射击游戏项目，围绕射击类游戏的基本设计与实现展开，旨在通过实际开发熟悉游戏逻辑编写、场景管理、资源整合以及交互玩法的实现流程。

本项目可作为学习 Unity 与 C# 游戏开发的实践项目，也可作为后续扩展游戏玩法的基础。

✨ 项目特点
🎯 射击玩法： 探索射击类游戏相关机制的设计与实现。
🎮 游戏交互： 实践玩家与游戏场景之间的交互逻辑。
💻 游戏编程： 使用 C# 编写游戏功能与逻辑。
🎨 资源管理： 使用 Unity 管理游戏场景及相关资源。

注：以上为项目方向介绍，具体已实现的功能请以仓库中的实际代码为准。

🚀 如何运行
环境准备
安装 Unity Hub。
安装与本项目兼容的 Unity Editor 版本。
安装 Git（如果需要通过 Git 克隆项目）。
获取项目

在终端中执行以下命令：

git clone https://github.com/XianWang12/Shooter.git
打开项目
启动 Unity Hub。
点击「添加」，选择克隆后的 Shooter 项目文件夹。
使用兼容的 Unity Editor 版本打开项目。
在 Assets 目录中找到游戏主场景。
打开场景后，点击 Unity 编辑器顶部的「播放」按钮运行游戏。
